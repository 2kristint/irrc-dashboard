# IRRC Dashboard

Iowa Reading Research Center (IRRC) Dashboard is a web application designed to help IRRC staff identify patterns in engagement and user experience. The analytic dashboard shows course traffic, user demographics, and participants' ratings and feedback. By translating complex Moodle data into clear visual graphs, this application helps staff evaluate course effectiveness and make informed decisions for course design. This is a full-stack application is built using MySQL, React, and Express tools.

## Getting Started

### Installation

Install all the required packages in the `client` and `server` directory

```
cd client && npm i

cd server && npm i
```

<p align="right">(<a href="#readme-top">back to top</a>)</p>

## Usage

To run the project locally

### Running client and server independently

#### Client

1.  Run the client by running `npm run dev` in the `/client` directory

#### Server

1.  Run the server by running `node server.js` in the `/server` directory
